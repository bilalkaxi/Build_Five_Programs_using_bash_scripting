# Build Five Programs Using Bash Scripting

A project completed as part of the [freeCodeCamp Relational Database Certification](https://www.freecodecamp.org/learn/relational-database/). This project focuses on writing Bash scripts to automate tasks and build interactive command-line programs.

## Overview

The project involves building five programs using Bash scripting, practicing shell commands, variables, conditional statements, loops, and user input.

## Technologies Used

- **Language:** Bash
- **Environment:** Linux / Unix Shell
- **Course:** freeCodeCamp Relational Database Certification

## Programs

The repository contains five Bash scripting programs developed to practice command-line programming and automation.

## Concepts Practiced

- Bash scripting fundamentals
- Variables and user input
- Conditional statements (`if`, `else`)
- Loops and iteration
- Functions
- Command-line arguments
- File handling and shell commands

## Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/bilalkaxi/Build_Five_Programs_using_bash_scripting.git
```

### 2. Navigate to the project directory

```bash
cd Build_Five_Programs_using_bash_scripting
```

### 3. Run a Bash script

```bash
bash questionnaire.sh countdown.sh bingo.sh fortune.sh
```
